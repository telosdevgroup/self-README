## ⚡ Origin: Hooked Early

- **4th Grade**: Picked up a physical book on HTML, coded a custom skateboarding website, monetized it with early banner ads, and made \$30 in internet ad revenue. The realization that typing markup into a text file could produce a live, globally accessible, cash-flowing asset changed everything.
- **6th Grade**: Wrote a CLI "guess a number between 1 and 10" game in BASIC on a vintage Apple II. Watching the machine evaluate input branches and execute control flow hooked me on computing permanently.

Every system since—from enterprise ERP ledgers to bare-metal Linux kernel daemons—stems from that same obsession: understanding how state machines work and bending hardware to intent.

## 🧭 Systems & Projects

- [AvaScry MTG Apex](projects/avascry.md) — Bare-metal search & archival engine indexing 808,000+ MTG printings. <1ms in-memory cache, prime-jitter harmonic dispersion, zero cloud cost ($0.00/mo), decoupled Ed25519 Discord webhook engine.
- [ChangeState](projects/changestate.md) — Autonomous prime-cadenced hardware actuation and thermal envelope manager for Linux. Zero dependencies, sysfs/ACPI kernel interfaces, Cinnamon applet + cluster orchestration.
- [avabatt](projects/avabatt.md) — Native Linux battery lifespan preservation & charge threshold manager. Directly actuates mainline `sysfs`, ThinkPad ACPI, and Lenovo VPC2004 EC nodes with zero daemons.
- [avathings-applet](projects/avathings-applet.md) — Native Cinnamon taskbar applet (`avathings@telosdevgroup`) for real-time hardware telemetry and non-blocking asynchronous GIO hardware control.
- [avathings-web](projects/avathings-web.md) — Agent-first bare-metal web platform ([avathings.com](https://avathings.com)) engineered for Generative Engine Optimization (GEO) with `/llms.txt` and semantic schema.
